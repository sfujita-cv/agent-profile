再現コマンド

リポジトリ root からコピペでそのまま通る形。

# 1. worktree 作成
scripts/create_agent_worktree.sh <name>

# 2. 検証実行（-- 以降は worktree root で実行される）
scripts/enter_agent_container.sh <name> -- <検証コマンド>

# 3. 後片付け（ユーザー判断）
scripts/remove_agent_worktree.sh <name>

未実行の手順があれば、その行に「未実行」と明記する。
